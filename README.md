# jimeng-drama-storyboard

AI真人短剧分镜 SKILL 版本档案（即梦/Jimeng 分镜脚本生成）。

## 版本演进

| 版本 | 名称 | 核心内容 |
| --- | --- | --- |
| v1 | 模板E定型版 | DeepSeek 总结计算版六段结构（先总结/计算/断点，再出分镜） |
| v2 | 长台词细分版 | 五种细分手法（反应穿插/语义断点/动作并行/物件空镜/OS错位）+ 真人短剧三铁律 |
| v3 | 机位三问版 | 机位三问（视角/突出/力量）+ 台词情绪标签 + 动作终点态 + 机位比例 |
| v4 | 导演七规则版 | 肌肉导演法/动作链拆解/机位三问/情绪标签/终点态/比例自查/角色锚点锁定 |
| v5 | 导演十五规则版 | v4 七基础 + 八进阶（语速多档/灯光剧情变量/集型机位/跨片段台词/运镜双语/道具符号/走位叙事/满负荷打包） |

## 目录结构

```
versions/
├── v1_模板E定型版/
├── v2_长台词细分版/
├── v3_机位三问版/
├── v4_导演七规则版/
└── v5_导演十五规则版/
    └── SKILL包/   ← 当前生效版（完整可部署：SKILL.md + references）
```

## 部署方法

取 `versions/v5_导演十五规则版/SKILL包/` 整个目录放入豆包 `.user_skills/` 或 `.skills/` 目录即可生效。

每个版本文件夹内含 `改版说明.txt`（该版本改动明细）与版本内容快照。
