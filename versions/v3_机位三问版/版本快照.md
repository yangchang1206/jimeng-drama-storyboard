# jimeng-drama-storyboard v3 · 机位三问版（版本快照）

> 说明：本文件为按历史对话里程碑**重建的快照**，非原始安装文件。原始 v3 未落盘保留，此处还原其核心规则，供版本演进追溯。

## 版本定位

引入 CSDN 机位"三问"原则（blog.csdn.net/Fang_YuanAI/article/details/165620201），把机位选择从直觉提升为可自检的决策流程；同步固化台词情绪标签与动作终点态写法。

## 机位三问原则（每镜必问）

| 问题 | 决定 |
| --- | --- |
| 观众应该站在谁的视角？ | 正面（旁观）/ 背面（代入）/ 过肩（关系） |
| 这一镜要突出什么？ | 表情→正面；动作→侧面；悬念/代入→背面 |
| 谁在这一刻更有力量？ | 仰拍（强势方）/ 俯拍（弱势方） |

三问答案必须写入镜头机位/角度说明，禁止空泛写"机位合理"。

## 台词情绪标签

| 标签 | 用途 |
| --- | --- |
| `[angry outburst]` | 愤怒爆发 |
| `[sarcastic]` | 讽刺 |
| `[cold threat]` | 冷厉威胁 |
| `[gentle whisper]` | 温柔低语 |
| `[panicked scream]` | 惊慌尖叫 |
| `[bitter laugh]` | 苦笑 |

## 动作终点态

- 动作必须写明**结束状态**，禁止动作截断。
- 正确："他转身，在门框处停顿半秒，然后彻底消失在门后"；"他转身，走到门口，推开门，消失在走廊尽头"。
- 禁止：只写"他转身离开"。

## 机位比例控制（初版）

| 机位 | 目标占比 | 核心用途 |
| --- | --- | --- |
| 正面 | 30-40% | 表情捕捉、交流 |
| 侧面 | 20-30% | 动作展示、过渡 |
| 背面 | 15-25% | 代入感、悬念 |
| 过肩 | 5-10% | 对话关系 |
| 俯拍/仰拍 | 各 5-10% | 力量对比 |
