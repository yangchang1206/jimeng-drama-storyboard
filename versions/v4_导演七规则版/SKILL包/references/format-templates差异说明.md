# v4 快照 references 差异说明

本文件夹的 `references/` 包含以下文件（与 v5 一致，未改动）：
- director-rules.md（v4 新增核心）
- camera-movements.md
- lighting-schemes.md
- special-angles.md
- pacing-and-revision.md

**format-templates.md 说明**：v4 时代该文件与 v5 的差异仅两处（均为 v5 升级）：
1. 语速口径：v4 为单档（普通对白 3.5 / OS 3 / 欢呼 5 字每秒）；v5 改为四档情绪仪表（喃喃3/常态3.5/对抗4/惊呼5），台词时长算到 0.1s。
2. 镜头时长：v4 为"有台词镜头 = 台词时长"；v5 改为"台词时长 + 0.2~0.5s 呼吸余量"，并增加片段满负荷打包（26~29.5s）原则。

其余部分（模板 E 六段结构、转场写法、景别/运镜写法、数值一致性）两版一致。
