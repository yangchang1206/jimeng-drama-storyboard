# jimeng-drama-storyboard v2 · 长台词细分版（版本快照）

> 说明：本文件为按历史对话里程碑**重建的快照**，非原始安装文件。原始 v2 未落盘保留，此处还原其核心规则，供版本演进追溯。

## 版本定位

针对"一个人物台词时间长、镜头拍人物太久显得枯燥"的问题，把**五种细分手法（按优先级）**与**真人短剧三铁律**固化为规则，应用到模板 E 中。

## 五种细分手法（按优先级）

长台词（单镜头超 8s）必须细分，优先级从高到低：

1. **① 反应镜头穿插**：台词进行中，切听者反应近景（表情/眼神/小动作），打断单一说话人画面。
2. **② 语义断点切镜**：按台词语义转折/换气点切镜（如"我答应你，但有个条件"拆两镜），切点选在语义停顿处。
3. **③ 动作与台词并行**：说话人边说边完成动作链（起身/走动/放杯），动作承接台词节奏。
4. **④ 物件/细节空镜**：插入关键物件特写（信/照片/礼物），让台词内容有视觉落点。
5. **⑤ OS 画面错位**：内心独白时画面不给说话人，给所看之物/回忆画面/环境细节。

## 真人短剧三铁律

1. **不抢话**：一句台词未说完，下一个人不得接话；切镜头用"硬切（XX反应）"承接，而不是让下一位直接开说。
2. **时长按台词长度给足**：短句（≤15字）1.5-2s；中句（15-40字）3-4s；长段（40字以上）5s 起，可标注"为完整台词留够时间"。
3. **关键节点必须补全台词**：呈礼、宣判、下跪、效忠等节点台词缺失会被退回。

## 细分附加规则

- 单镜头台词 8-20 字为宜；每个切点必须写明切点理由（反应/动作/物件/景别变化），无理由的切就是乱切。
- 区分 OS 与 VO：内心独白用"人物OS"，画外音用"人物VO"，写进画面描述列。
